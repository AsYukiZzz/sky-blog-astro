## 一条记录，也可以有完整的格式

瞬间适合记录简短的想法，也支持 Markdown 排版。本示例展示 **粗体**、_斜体_、~~删除线~~ 和 `行内代码`。🌱

### 列表与待办

- 留下今天的一个想法。
- 分享一段代码或一张图片。
    - 用子列表补充细节。

1. 先记录。
2. 再整理。

- [x] 写下内容。
- [ ] 换成自己的记录。

### 引用

> 有些想法只有一句话，也值得拥有自己的位置。

### 代码块

代码围栏后标注语言，可以显示语法高亮，并通过代码框中的按钮复制内容。

```js
const moment = {
    text: '把今天的小小发现留下来',
    tags: ['日常', '灵感'],
};

console.log(moment.text);
```

```sh
pnpm dev
```
