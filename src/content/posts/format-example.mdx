## 文字强调与链接

普通文字可以搭配 **粗体**、_斜体_、**_粗斜体_** 和 ~~删除线~~。

行内代码适合表示文件名、命令或变量，例如 `src/content/posts/`、`pnpm build` 和 `publishedAt`。

链接可以指向 [Astro 官网](https://astro.build/)，也可以指向站内的 [瞬间格式示例](/moments/format-example/)。

## 代码块

代码围栏后写语言名称，可以启用对应的语法高亮。代码框右上角可以复制代码。

### TypeScript

```ts
interface Post {
    title: string;
    tags: string[];
}

const post: Post = {
    title: '我的第一篇文章',
    tags: ['astro', 'markdown'],
};

console.log(`${post.title}：${post.tags.join('、')}`);
```

### Shell 命令

```sh
pnpm install
pnpm dev
pnpm build
```

### JSON

```json
{
    "title": "格式示例",
    "draft": false,
    "tags": ["astro", "markdown"]
}
```

### 普通文本

```text
src/content/
├── posts/format-example.mdx
└── moments/format-example.md
```
